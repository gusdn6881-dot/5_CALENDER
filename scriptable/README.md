# 💑 부부 전용 커스텀 캘린더 & 할 일 위젯 가이드 (0원 완전 무료)

애플 개발자 계정(연 99달러) 결제 없이, 아이폰 순정 기능과 무료 앱 **Scriptable**을 활용하여 두 분만의 맞춤형 홈 화면 위젯을 사용하는 방법입니다.

---

## 📱 1단계: 부부 공유 캘린더 & 미리 알림 만들기 (최초 1회)

두 분의 아이폰 간에 일정이 실시간 동기화되도록 애플 기본 공유 설정을 켭니다.

### A. 공유 캘린더 (일정)
1. 아이폰 기본 **[캘린더]** 앱 실행
2. 화면 하단 가운데 **[캘린더]** 터치
3. 좌측 하단 **[캘린더 추가]** > 이름 입력 (예: `우리캘린더`) 및 색상 선택
4. 생성된 캘린더 우측의 **(i) 버튼** 터치 > **[구성원 추가]** 터치
5. **아내분의 연락처 또는 Apple ID(이메일)** 입력 후 초대 전송
6. 아내분 폰에서 초대를 승낙하면 즉시 두 사람의 캘린더가 하나로 연동됩니다!

### B. 공유 미리 알림 (할 일/장보기)
1. 아이폰 기본 **[미리 알림]** 앱 실행
2. 우측 하단 **[목록 추가]** > 이름 입력 (예: `부부 할 일`)
3. 우측 상단 **··· 버튼** > **[목록 공유]** 터치 후 아내분 초대

---

## 🎨 2단계: 위젯 앱 설치 및 코드 등록

1. 두 분의 아이폰에서 각각 App Store를 열고 **[Scriptable](https://apps.apple.com/app/scriptable/id1405459188)** (무료, 완전 0원) 검색 후 설치
2. Scriptable 앱을 엽니다.
3. 우측 상단 **+ 버튼**을 눌러 새 스크립트 생성
4. 상단 스크립트 이름을 터치하여 **`우리캘린더`**로 변경
5. [CoupleCalendarWidget.js](CoupleCalendarWidget.js) 파일의 전체 코드를 복사하여 그대로 붙여넣기
6. 우측 하단 **재생(▶) 버튼**을 누르면 샘플 화면이 예쁘게 뜨는 것을 확인 후 저장(Done)

---

## 📲 3단계: 아이폰 첫 화면(홈 화면)에 위젯 띄우기

1. 아이폰 홈 화면 빈 공간을 길게 꾹 누릅니다 (아이콘들이 흔들리는 편집 모드).
2. 좌측 상단의 **+ 버튼** 터치
3. 위젯 목록에서 **[Scriptable]** 선택
4. 가로로 넓은 **Medium(직사각형) 크기**를 선택하고 **[위젯 추가]** 터치
5. 홈 화면에 추가된 빈 위젯을 톡 터치 (또는 길게 눌러 **[위젯 편집]**)
6. **Script** 항목을 눌러 방금 만든 **`우리캘린더`** 선택
7. **When Interacting(터치 시 동작)**은 **`Open App`** 또는 **`Run Script`** 선택
8. 홈 화면으로 나오면 **오늘 날짜 + D-Day + 오늘 일정 + 오늘 할 일**이 깔끔하게 표시됩니다!

---

## ⚙️ 커스텀 설정 팁

`CoupleCalendarWidget.js` 파일 상단의 `CONFIG` 부분에서 원하는 대로 변경하실 수 있습니다:

```javascript
const CONFIG = {
  anniversaryName: "결혼기념일", // D-Day 뱃지 이름
  anniversaryDate: "2024-05-18",  // 두 분의 기념일 날짜 (YYYY-MM-DD)
  accentColor: "#4A90E2",        // 메인 블루 색상
  loveColor: "#FF6584",          // D-Day 핑크 포인트 색상
};
```
