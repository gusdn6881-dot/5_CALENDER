# 📱 우리의 캘린더 - 부부 전용 PWA 웹앱

아이폰과 갤럭시 모두에서 앱스토어 설치 없이 **바탕화면에 나만의 단독 앱 아이콘**을 만들고, 전체 화면으로 쓸 수 있는 부부 공유 캘린더 & 할 일 앱입니다.

---

## ✨ 핵심 기능

1. **앱스토어 등록 불필요 (0원)**: 1년 14만 원 개발자 등록비 없이 평생 무료 사용
2. **진짜 앱과 동일한 사용 경험 (PWA)**: 브라우저 주소창 없이 전체 화면 구동, 홈 화면 아이콘 제공
3. **부부 특화 기능**:
   - 상단 결혼기념일 / D-Day 실시간 계산 뱃지
   - 월별 달력 뷰 (날짜별 일정 도트 표시)
   - 오늘 및 선택된 날짜의 일정 목록
   - 부부 할 일 & 장보기 체크리스트
   - 오프라인 지원 (인터넷 없어도 로컬 저장) 및 Supabase 클라우드 실시간 동기화 지원

---

## 📲 스마트폰에 앱으로 설치하는 방법

### A. 아이폰 (iOS Safari)
1. 아이폰의 **Safari(사파리)** 브라우저로 배포된 웹사이트 주소에 접속합니다.
2. 화면 하단 가운데 **[공유 버튼 (네모에 위쪽 화살표)]** 터치
3. 메뉴를 아래로 내려 **[홈 화면에 추가]** 터치
4. 우측 상단 **[추가]** 터치
5. 아이폰 바탕화면에 **'우리캘린더'** 앱 아이콘이 생성되며, 누르면 일반 앱처럼 전체 화면으로 실행됩니다!

### B. 갤럭시 (Android Chrome / 삼성 인터넷)
1. 갤럭시에서 브라우저로 웹사이트 접속
2. 화면 하단 또는 우측 상단 메뉴에서 **[홈 화면에 추가]** 또는 **[앱 설치]** 팝업 터치
3. 스마트폰 홈 화면에 전용 앱으로 설치 완료!
