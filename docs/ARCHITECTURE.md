# Calender (아이폰 & 갤럭시 동기화 캘린더) 시스템 아키텍처

본 문서는 아이폰(iOS)과 갤럭시(Android) 간의 실시간 캘린더/할 일 동기화 및 모바일 홈 화면 위젯 연동을 위한 정식 앱 아키텍처를 정의합니다.

---

## 1. 시스템 핵심 요구사항

1. **플랫폼 독립성**: iOS와 Android에서 픽셀 단위로 일치하는 UI 및 부드러운 사용감 제공 (Flutter)
2. **유연한 공유 모델**:
   - **개인 모드**: 한 사용자가 소유한 여러 기기(아이폰, 갤럭시, 태블릿 등) 간 1초 이내 자동 동기화
   - **2인/소규모 공유 모드**: 연인/부부/가족 간 캘린더 공유 및 색상/권한 구분
   - **다인원 그룹/팀 모드**: 스페이스(워크스페이스) 단위 멤버 초대, 역할별 권한(관리자/편집자/뷰어) 제어
3. **통합 생산성 허브**:
   - 시간 기반 **일정(Event)**: 특정 일시, 종일 일정, 반복 규칙(RRULE)
   - 실행 기반 **할 일(To-do)**: 기한, 우선순위, 체크 완료 여부, 일정과 연계
   - 컨텍스트 기반 **메모(Memo)**: 특정 날짜 또는 특정 일정에 종속된 텍스트 메모
4. **홈 화면 위젯(Widget)**:
   - 스마트폰 첫 화면에서 앱을 열지 않고도 오늘의 일정 및 할 일 즉시 확인
   - 위젯 터치 시 해당 일정의 상세 페이지 또는 일정 등록 모달로 즉시 딥링크

## 3. 홈 화면 위젯 연동 메커니즘

1. **데이터 캐싱**:
   - Flutter 앱에서 Supabase로부터 일정을 동기화하거나 사용자가 일정을 수정/추가할 때마다, `home_widget` 플러그인을 통해 OS별 네이티브 공유 저장소로 오늘/내일의 요약 JSON 데이터를 저장합니다.
   - iOS: `App Group` 기반 `UserDefaults`
   - Android: `SharedPreferences`
2. **위젯 리로드 트리거**:
   - `home_widget.updateWidget(name: 'CalendarWidgetProvider')` 호출
   - iOS는 `WidgetCenter.shared.reloadTimelines(ofKind: "CalendarWidget")` 실행
   - Android는 `AppWidgetManager.getInstance(context).notifyAppWidgetViewDataChanged()` 실행
3. **위젯 클릭 인터랙션**:
   - 위젯 내 특정 일정 터치 시 딥링크 스킴(`calender://event?id={eventId}`)을 통해 Flutter 앱의 특정 화면으로 직행
